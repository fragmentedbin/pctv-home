# Contributing to PCTV Home

Thanks for helping. Bug reports, ideas and pull requests are all welcome.

## Before you start

- **Bugs:** open an issue with your OS and version, browser (Chrome/Edge + version), phone, and what you expected vs. what happened. A photo of the TV helps a lot.
- **Bigger changes:** open an issue first so we can agree on the approach.

## Setup

```bash
npm install
npm run dev        # Electron app, restarts on server changes and reloads pages on UI changes
npm test
```

`npm run server:kiosk` runs the server without Electron, which is handy on Linux. Native input there is a no-op logger, and set `PCTV_DEBUG_INPUT=1` to see the keys that would have been sent.

## Project layout

```
src/main/            Electron app: tray/menu bar, control panel window, start-at-login
src/server/          HTTP + WebSocket server (also runs headless via cli.js)
  lib/browser.js     Chrome/Edge kiosk + DevTools control (Home/Back, TV user agent, focus hook)
  lib/tv-nav.js      D-pad navigation injected into normal websites
  lib/input/         native keyboard/mouse: win32.js (SendInput) · darwin.js (CGEvent)
  lib/stats/         battery / Wi-Fi / ping per OS
  lib/power.js       sleep, restart, shut down
src/public/          launcher (TV home), remote (phone), panel (desktop window), brand assets
build/               icons and installer resources (generated by scripts/make-icons.py)
```

## Guidelines

- Keep it **local-first**: no accounts, no telemetry, nothing leaves the user's network.
- No helper scripts at runtime (PowerShell, AppleScript files, .bat). They break under Windows Smart App Control. Use direct system calls (koffi) or built-in, signed OS tools.
- Test on the platform you change. If you can only test one OS, say so in the PR.
- Match the existing style (2-space indent, small modules, comments that explain *why*).
