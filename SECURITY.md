# Security

PCTV Home can press keys and move the pointer on the computer it runs on, so the phone remote is protected by a pairing key, and the browser control port (DevTools) listens on `127.0.0.1` only.

If you find a vulnerability, please **don't open a public issue**. Email muhammadmaududy4@gmail.com with the details and steps to reproduce. You'll get a reply within a few days.
